3. Remediation Details

During internal scientific audit, the following technical discrepancies were identified and remediated:

Causal State Update Fix
Detectors, robust normalization, and adaptive gating now score the current observation before incorporating it into future state.
Provenance-Controlled Data
Benchmark loading requires a sidecar manifest with source, license, label semantics, synthetic status, and checksum; synthetic data is opt-in for smoke tests only.
Explicit Null Evaluation
The stream protocol reports chronological warm-up, a persistence baseline, IAAFT surrogate statistics, empirical significance, and per-detector results.
VUS Score Inflation Fix
apply_range_buffer was erroneously applied to both ground-truth labels and predicted anomaly scores. Corrected to buffer labels only.
Detector Naming Realignment
Two detectors were renamed to accurately reflect their underlying mathematical structures (ARFilterDetector and MSETransformerAutoencoder).
Reference Comparison Removal
External comparative claims against closed-source references were removed due to metric and evaluation protocol mismatches.
Unit Test Fixes
Resolved three failing tests by correcting StreamBuffer __len__ calculation, MetaJudge convex fusion normalization, and FNN threshold calibration.

6. Adding a New Detector Module

All detector modules in the 6-detector battery implement the DetectorABC contract defined in src/tsad/detectors/base.py: 

from abc import ABC, abstractmethod
import numpy as np
from typing import Tuple

class DetectorABC(ABC):
    @abstractmethod
    def score(self, Z_t: np.ndarray, v_t: float) -> Tuple[float, float]:
        """
        Calculates instantaneous anomaly score s_t in [0, 1] 
        and forward forecast v_hat_{t+h}.
        """
        pass

    @abstractmethod
    def update(self, v_true: float):
        """
        Updates internal model state with newly observed true scalar v_t.
        """
        pass

Steps to Register a New Detector:

  1. Create a module file in src/tsad/detectors/your_detector.py inheriting from DetectorABC.
  2. Calibrate raw output scores $s_t \in [0, 1]$ using robust median/MAD statistics so normal baseline output is $\approx 0.0$.
  3. Register the detector class in src/tsad/pipeline.py inside self.detectors.
  4. Update K_DETECTORS in src/tsad/config.py.
  5. Add unit tests in tests/unit/test_detectors.py.
