# Security Policy

## Reporting Security Vulnerabilities

The maintainers of `open-phase-ensemble` take security seriously. If you discover a security vulnerability or potential risk in this repository or its dependencies, please **do not** open a public issue.

Instead, please send a security report to the maintainers or submit a private security advisory via GitHub Security Advisories.

### Response Timeline
- **Acknowledgement**: Within 48 hours.
- **Assessment & Patch**: Within 14 days for critical vulnerabilities.
