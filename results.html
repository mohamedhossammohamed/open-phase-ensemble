2. Benchmark Evaluation

The repository contains a provenance-checked evaluation protocol using Volume Under Surface metrics (VUS-ROC and VUS-PR). Range buffering is applied strictly to ground-truth labels only — predicted anomaly scores are never expanded.

Performance is benchmarked against Iterative Amplitude Adjusted Fourier Transform (IAAFT) phase-randomized surrogate null series scored under identical conditions.

Dataset $N$ System VUS-ROC System VUS-PR IAAFT Null VUS-ROC Edge ($\Delta$) Status
PhysioNet MIT-BIH (rec 100) 5,000 0.9354 0.0303 0.5030 +0.4324 Validated (+43.2% edge)
CWRU Bearing Transition Proxy 5,000 0.6434 0.5223 0.3347 +0.3087 Validated (+30.9% edge, p=0.047)

A positive predictive edge is only an empirical comparison against the chosen surrogate null; it does not by itself confirm nonlinear pattern recognition. That interpretation requires repeated surrogates, a pre-specified protocol, uncertainty intervals, and independent replication.

3. Known Limitations & Audit Findings

An internal code and scientific integrity audit identified and remediated three major issues prior to release:

1. Evaluation Metric Correction
An earlier version of src/tsad/evaluation/vus.py applied apply_range_buffer to both ground-truth labels and predicted scores. This artificially inflated VUS-ROC by approximately +0.06 to +0.12. The code now buffers labels only, consistent with formal VUS definitions.
2. Detector Naming Alignment
Two detectors were renamed to accurately describe their actual mathematical implementations: ARFilterDetector (batch AR ridge filter, refit periodically, replacing "SARIMADetector") and MSETransformerAutoencoder (MSE sequence reconstruction, replacing "AnomalyTransformerDetector").
3. Reference Comparison Validity
Direct numerical comparison to the closed-source phase_space_matcher reference (83.96–86.02%) was flagged as scientifically invalid due to metric mismatch (PA-F1 vs VUS-ROC) and subsampling differences. External comparative claims were removed.

4. Metric Definitions

Volume Under Surface ROC (VUS-ROC) integrates AUC-ROC curves across a continuum of temporal buffer thresholds $l \in [0, L_{\max}]$ ($L_{\max} = 15$). Range buffering expands ground-truth label regions only:

$$\text{VUS-ROC} = \frac{1}{L_{\max} + 1} \sum_{l=0}^{L_{\max}} \text{AUC-ROC}(\text{labels}_l, \text{scores})$$

Predictive Edge ($\Delta$): Defined as $\Delta = \text{VUS-ROC}_{\text{system}} - \text{VUS-ROC}_{\text{IAAFT}}$. A positive edge $\Delta > 0$ indicates non-linear predictive power beyond phase-randomized linear autocorrelation.
