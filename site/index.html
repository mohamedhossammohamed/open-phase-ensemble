01 · Overview

Methodological Philosophy

Time-series anomaly detection suffers from methodological fragmentation. Flawed metrics like point-adjusted F1 (PA-F1) inflate random guessers to >90% accuracy, while deep learning models remain black boxes. open-phase-ensemble offers a transparent, non-parametric alternative.

01

Non-Parametric Geometry

Reconstructs attractor manifolds via Takens' delay embedding rather than fitting millions of neural weights.

02

Orthogonal 6-Detector Battery

Combines trajectory predictability, covariance geometry, matrix profile discords, subspace isolation, linear AR residuals, and transformer autoencoding.

03

Online Meta-Judge

Hedge multiplicative weights dynamically adjust expert weights in real time without requiring ground-truth anomaly labels.

04

Zero-Lookahead Invariant

Strict element-by-element online evaluation. No future window observations are ever leaked during scoring.

05

Un-Buffered VUS Metrics

Evaluated using Volume Under Surface (VUS-ROC) with label-only temporal buffering, benchmarked against IAAFT surrogate null models.

06

Self-Audited Integrity

Disclosed all metric corrections, renamed over-claimed detector modules, and documented limitations openly.

02 · Architecture

System Pipeline Overview

The system operates as a zero-lookahead streaming loop. Data flows strictly forward through pre-processing, feature space projection, detector scoring, expert fusion, and CUSUM adaptation gating.

04 · Scientific Rigor

Known Limitations & Audit Remediations

Scientific integrity requires publishing corrections openly. The following remediations were implemented during our internal code and results audit:

1. VUS Metric Correction

An internal audit identified a bug in earlier metric calculation where predicted anomaly scores were max-pooled alongside ground-truth labels. Range buffering is now applied strictly to ground-truth labels. All reported numbers reflect this un-inflated evaluation.

2. Algorithmic Realignment

Two detector modules were renamed to accurately describe their actual mathematical implementations: ARFilterDetector (online AR ridge regression filter) and MSETransformerAutoencoder (MSE sequence reconstruction).

3. Reference Comparison Invalidity

Direct comparison to external closed-source references (e.g. 83.96–86.02%) is scientifically invalid due to metric type mismatch (VUS-ROC vs. PA-F1) and dataset length differences. We report our VUS-ROC numbers independently without claiming superiority.

4. Future Work & Multi-Seed Bounds

Current benchmark figures are single-run point estimates. Multi-seed evaluations to generate 95% confidence intervals ($\pm \sigma$) are planned for a future release to further validate the preliminary estimates.

Python Streaming Usage

from tsad.pipeline import TSADPipeline

# Initialize pipeline (tau=2, d=8)
pipeline = TSADPipeline(tau=2, d=8)

# Process scalar stream online (zero-lookahead)
stream = [0.1, 0.2, 0.15, 0.18, 8.5, 0.12]

for x_t in stream:
    A_t, v_hat = pipeline.step(x_t)
    print(f"x_t={x_t:5.2f} -> Anomaly Score: {A_t:.4f}, Forecast: {v_hat:.4f}")
